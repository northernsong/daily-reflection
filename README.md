# Daily Reflection - 吾日三省吾身

一个帮助用户在碎片化时间内，持续学习和巩固知识的系统。通过AI驱动的智能题目生成和自适应复习，帮助用户应对上级询问、客户咨询、面试等真实场景。

## 核心理念

**吾日三省吾身** —— 日日反思，持续进步
- 📚 上传学习资料 → AI智能提取知识点
- 🎯 定时智能出题 → 巩固知识，对标实际应用
- ⏱️ 利用碎片时间 → 简短高效的复习体验
- 🚀 应对真实场景 → 上级询问、客户咨询、面试等

## 系统架构

### 后端（Java）
- RESTful API 服务
- AI知识点解析与管理
- 题目生成与管理
- 用户学习进度追踪
- 自适应复习策略

### 前端（Flutter）
- 跨平台移动应用
- 资料上传与管理
- 智能出题与答题
- 学习统计与反馈
- 离线支持

## 工作流程

1. **资料上传阶段**
   - 用户在App中上传学习资料（文档、笔记等）
   - 支持多种格式（PDF、图片、文本等）

2. **智能解析阶段**
   - 后端AI解析资料内容
   - 提取核心知识点
   - 构建知识图谱

3. **复习测试阶段**
   - 系统定时推送简短问题
   - 问题简洁高效，适合碎片时间
   - 基于用户答题情况调整难度和出题频率

4. **场景应用阶段**
   - 帮助用户在真实场景中应用知识
   - 应对上级询问、客户咨询、面试等挑战

## 技术栈

- **后端**: Java, Spring Boot, AI/LLM 集成
- **前端**: Flutter, Dart
- **数据库**: MySQL / PostgreSQL
- **部署**: Docker, Kubernetes（可选）

## 快速开始

### 后端
```bash
cd server
mvn spring-boot:run
```

### 前端
```bash
cd app
flutter pub get
flutter run
```

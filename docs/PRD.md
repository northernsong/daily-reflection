## 2. 产品概述

### 2.1 一句话定位

一个帮助用户在碎片化时间内持续学习、巩固知识的系统。通过 AI 驱动的知识点提取、智能出题和自适应复习，帮助用户从容应对上级询问、客户咨询、面试等真实场景。

### 2.2 核心理念

**吾日三省吾身** —— 通过每日高频、简短的复习，把学过的资料真正内化为可随时调用的能力。

- 📚 上传学习资料 → AI 智能提取知识点
- 🎯 定时智能出题 → 巩固知识，对标实际应用
- ⏱️ 利用碎片时间 → 简短高效的复习体验
- 🚀 应对真实场景 → 上级询问、客户咨询、面试等

### 2.3 要解决的问题

| 痛点 | 说明 |
| --- | --- |
| 学了就忘 | 资料读过一遍后缺乏系统的回顾机制，遗忘曲线陡峭 |
| 没有整块时间 | 工作繁忙，难以抽出连续时间复习 |
| 复习无重点 | 不知道哪些知识点掌握薄弱、该优先复习什么 |
| 临场答不上 | 被上级/客户/面试官问到时，明明学过却无法准确表述 |

### 2.4 目标用户

- 需要持续吸收新知识的职场人（技术、销售、咨询、运营等）
- 准备面试、认证考试的求职者/学习者
- 有大量文档、笔记积累但缺乏复习习惯的知识工作者

## 4. 功能需求详述

### 4.1 资料上传与管理

- 支持格式：纯文本、Markdown、PDF、图片（JPG/PNG，走 OCR）。
- 单文件大小与总容量限制由后端配置（默认单文件 ≤ 20MB）。
- 上传后展示解析状态：待解析 / 解析中 / 已完成 / 失败（可重试）。
- 支持对资料打标签、重命名、删除。

**验收标准**
- 上传 PDF 后，能在列表看到解析进度并最终生成知识点。
- 图片上传后能通过 OCR 提取文字并进入解析流程。

### 4.2 AI 知识点提取

- 后端调用 LLM 将资料内容拆解为原子化知识点（标题 + 要点 + 出处）。
- 每个知识点关联来源资料与位置信息，便于溯源。
- 支持用户对自动生成的知识点进行编辑、合并、删除。

**验收标准**
- 一份资料解析后生成 ≥ 1 条结构化知识点，且可编辑保存。

### 4.3 智能出题

- 题型：单选、多选、填空、简答（一期）。
- 出题基于知识点内容，题干贴近"真实场景提问"（如上级/客户/面试口吻）。
- 支持一键为某个知识点/某份资料生成一组题目。

**验收标准**
- 针对任一知识点可生成题目并保存到题库。

### 4.4 定时推送与碎片化复习

- 用户可设置每日复习时间段与提醒频率。
- 到点通过通知推送，点击进入"今日复习"，每次呈现少量题目（默认 3~5 题）。
- 单次复习控制在几分钟内完成。

**验收标准**
- 到设定时间收到通知，点击可直接进入答题。

### 4.5 答题与判分

- 客观题（单选/多选/填空）自动判分。
- 简答题由 AI 给出评分与改进建议，用户可自评修正。
- 答题结果计入统计与自适应策略。

**验收标准**
- 客观题即时反馈对错；简答题给出 AI 评估结果。

### 4.6 自适应复习策略

- 采用间隔重复（Spaced Repetition，如 SM-2 变体）安排复习间隔。
- 掌握度高的知识点延长间隔、降低出现频率；薄弱的加密复习。
- 难度随正确率动态调整。

**验收标准**
- 连续答对的知识点复习间隔变长，答错的间隔缩短。

### 4.7 学习统计

- 展示：知识点掌握度分布、累计复习数、连续打卡天数、薄弱知识点 Top N。

**验收标准**
- 完成若干次复习后，统计页数据随之更新。

## 5. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 性能 | 常规页面首屏 < 1s；AI 解析/出题为异步任务，前端展示进度 |
| 可用性 | 一期核心链路可用性 ≥ 99% |
| 安全 | 传输 HTTPS；用户资料与知识点仅本人可见；遵循苹果隐私规范 |
| 隐私 | 明确告知资料将上传后端做 AI 解析；提供数据删除能力 |
| 离线 | 已下载题目可离线作答，网络恢复后同步结果 |
| 兼容性 | 支持近两个大版本的 iOS / iPadOS / macOS |

## 6. 技术选型

### 6.1 前端（App）

**一期采用原生苹果技术栈，不使用 Flutter。**

- **语言**：Swift
- **UI 框架**：SwiftUI（一套代码适配 iOS / iPadOS / macOS，iPad 使用分栏/多列布局）
- **架构**：MVVM + Swift Concurrency（async/await）
- **本地存储**：SwiftData 或 Core Data（离线题目与缓存）
- **网络**：URLSession + Codable
- **推送/通知**：UserNotifications（本地通知）+ APNs（远程推送）
- **登录**：Sign in with Apple
- **分发**：App Store / TestFlight

> iPad 适配要点：使用 `NavigationSplitView` 实现侧边栏 + 内容分栏；支持多窗口（Scene）、键盘快捷键，充分利用大屏。

### 6.2 后端（Server）

- **语言/框架**：Java + Spring Boot
- **能力**：RESTful API、AI/LLM 集成（知识点提取、出题、简答评估）
- **数据库**：MySQL 或 PostgreSQL
- **对象存储**：用于存放上传资料（如 S3 兼容存储）
- **异步任务**：解析/出题等耗时操作走异步队列
- **部署**：Docker，Kubernetes（可选）

## 7. 用户核心流程

1. **资料上传阶段**：用户在 App 上传学习资料（文档、笔记、图片）。
2. **智能解析阶段**：后端 AI 解析内容，提取结构化知识点。
3. **复习测试阶段**：系统定时推送简短题目，用户利用碎片时间作答。
4. **场景应用阶段**：通过贴近真实场景的题目，帮助用户从容应对询问与面试。
